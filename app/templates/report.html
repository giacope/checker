How this report was made

{% for s in r.sources %}{% endfor %}
{{ s.id }}{{ s.adapter or s.kind }} {{ s.adapter_version or "" }}{% if s.model %} · {{ s.model }}{% endif %}{% if s.files_analysed %} · {{ s.files_analysed }} files{% endif %}{% if s.files_sent %} · {{ s.files_sent }} files read by the model{% endif %}{% if s.lockfiles %} · {{ s.lockfiles | join(", ") }}{% endif %}

Facts are extracted by deterministic static analysis and, where configured, a language model reading the code; each fact cites the line it rests on. Rule packs then decide each requirement: fails and passes hold for every value the sources allow, uncertain means sources disagree on a deciding fact, needs input means a fact the code cannot show (a contract, the deployment) is open. Packs are drafts written from the published texts; each requirement states how it is read. This is an automated assessment, not legal advice or a certification.
