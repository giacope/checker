How this report was made

{% for s in r.sources %}{% endfor %}
{{ s.id }}{{ s.adapter or s.kind }}{% if s.file %} · {{ s.file }}{% endif %}{% if s.schema %} · {{ s.schema }}{% endif %}{% if s.files %} · {{ s.files | length }} file{{ "s" if s.files | length != 1 }}{% endif %}{% if s.method %}
{{ s.method }}
{% endif %}

IFC models are read for their elements, property sets and quantities, and travel distances are computed from the floor geometry. PDF sheets are read from their text layer, or by OCR where the text is drawn as outlines or scanned; DXF drawings for their room boundaries, door blocks, dimensions and text. Every fact cites the sheet region or model element it was read from. Rule packs then decide each requirement: fails and passes hold for every value the sources allow, uncertain means sources disagree on a deciding fact, needs input means a classification the drawings don't show is open. Packs are drafts written from the published codes. This is an automated pre-check, not a plan review, approval, or certification.
